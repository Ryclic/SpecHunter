# Project instructions

Before starting work, read:
- `agents/PROJECT_CONTEXT.md` for project constraints and working agreements.
- `agents/HANDOFF.md` for implementation status, validation, and next steps.
- `agents/CHIA_PROPOSAL.md` for the research proposal.

Before creating or updating a pull request description, read and follow
`.github/pull_request_template.md`. This applies to CLI-created PRs as well.

Update `agents/HANDOFF.md` after substantial work, recording completed changes,
validation, blockers, and next steps.
